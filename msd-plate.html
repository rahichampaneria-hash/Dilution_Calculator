MSD Plate Planner

Lay out an MSD (Meso Scale Discovery) 96-well plate: a standard curve plus uploaded samples (CSV or Excel), following conventional MSD assay setup, with freeform well/row/column labels and CSV export.

Standard curve

Defaults match the conventional MSD setup: a 7-point, 4-fold serial-diluted curve plus a zero calibrator, run in duplicate down rows A–H in columns 1–2. Every value here is editable.

Sample start column defaults to just after the standard block, and updates automatically when you change the standard start column or replicate count — unless you edit it yourself. Standards and samples must not overlap.

Samples

Upload a CSV or Excel (.xlsx/.xls) file with sample names and concentrations. Columns: SampleName, Concentration, Unit (a header row and blank lines are fine; Unit is optional and falls back to the top calibrator's unit). Excel files are read entirely in your browser — nothing is uploaded anywhere.

Use this when your samples live on one sheet of a larger workbook, or the columns aren't in SampleName/Concentration/Unit order — pick the worksheet and column letters below (read them off the preview), then Generate as usual.

Samples fill left-to-right then top-to-bottom from the start column, in adjacent-well replicate blocks, across all 8 rows. Leaving the file empty previews the standard curve alone.

Shareable links reproduce the standard curve setup only — the uploaded sample file isn't included and needs to be re-attached.

Row/column headers and each individual well are editable — click a header to relabel a row or column (e.g. "TA3"), or click a well's "Note…" line to annotate it directly, so you can plan a general layout (donor pairings, treatment ratios) beyond just this standard curve.
